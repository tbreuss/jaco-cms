Jaco CMS features

Jaco CMS is for small static websites: keep an existing site, or start a new one from plain HTML. The editor is added only where content needs to change.

Edit the site in place

Open a page on the live site, click a marked region and edit it. There is no separate content form and no publish step.

  • Inline editing: text, headings, links, images and embedded videos in the page itself.
  • Rich text: headings, bold/italic, lists, quotes, code and links with a familiar toolbar.
  • Content blocks: recurring sections that editors add, fill and reorder by drag and drop.
  • Media library: reuse uploaded images and files instead of uploading duplicates.

Manage pages and media

  • Page manager: create pages from templates, copy them and delete them; backups are taken before changes.
  • Uploads: images and documents with extension checks and size limits; galleries create full-size versions.
  • Stylesheets: edit the site CSS from the admin panel, with the same backup protection as pages.
  • Page settings: edit the page title, meta description and robots value without touching the HTML source.
  • Site templates: maintain reusable HTML fragments under jaco-data/templates/site/ and apply one to every marked element across the public pages.
  • Roles: admin, editor and viewer accounts; viewers can inspect the site without changing it.

Keep changes safe

  • Backups: every overwrite or delete keeps a timestamped copy; restore with one click.
  • Login: token-based authentication, throttled against repeated failures.
  • Read-only handover: viewer accounts and maintenance mode keep accidental changes out.

Run it on your own host

  • No database: the pages are the database. Everything lives in plain HTML files.
  • No build step: PHP 8.2 or newer on a typical shared host with the required extensions.
  • No lock-in: remove the markers and Jaco CMS, and the HTML still works.
  • Four admin languages: English, German, French and Italian.

What Jaco CMS is not

Jaco CMS is not a visual page builder, a database CMS or a multi-tenant platform. It is a focused editor for small static sites. The HTML and design are yours – existing or new. That constraint is what keeps the files portable and the setup small.
