Jaco CMS features

Jaco CMS manages the static HTML files of a website directly in the web directory. The pages are the database: there is nothing to install besides PHP itself, no database server, no build step.

Editing

  • Inline editor: edit pages on the live site, in place, with rich text, images, links and embedded videos.
  • Page manager: create pages from templates, copy and delete them, with automatic backups before every change.
  • Content blocks: recurring sections (news, teasers) that editors add, remove and reorder by drag and drop in draggable lists – no developer needed per entry.
  • Image gallery: thumbnails link to full versions, generated from uploads.
  • Stylesheets: edit the site CSS from the admin panel, with backups like pages.

Operating

  • Backups: every overwrite or delete keeps a timestamped copy; one click restores.
  • Uploads: images and files with extension checks and size limits.
  • Login: token based (JWT), throttled against brute force, maintenance mode that locks writes in the admin.
  • Languages: the admin interface speaks English, German, French and Italian.
  • Requirements: PHP 8.2 or newer on any shared hoster. That is all.
