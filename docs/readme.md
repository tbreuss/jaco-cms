# Maintainer documentation

Markdown here uses **lowercase** file names. Several words are joined with **hyphens**
(`menu-structure.md`, `backend-naming.md`); a single word is fine (`features.md`,
`backlog.md`). This index is **`readme.md`**; GitHub renders it automatically in the
`docs/` folder (README names are case-insensitive).

Standard entry points at the repository root stay uppercase: `README.md`, `CONTRIBUTING.md`,
`INSTALL.md`.

| [backend-naming.md](backend-naming.md) | PHP function and file naming in the backend |

Contributing process: [CONTRIBUTING.md](../CONTRIBUTING.md). Installation for
site operators: [INSTALL.md](../INSTALL.md).
