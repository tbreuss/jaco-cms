[LICENSE](../LICENSE) lives in this directory.

(`menu-structure.md`, `backend-naming.md`); a single word is fine (`features.md`,
`backlog.md`). This index is **`readme.md`**; GitHub renders it automatically in the
`docs/` folder (README names are case-insensitive).
