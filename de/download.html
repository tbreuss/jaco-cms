Jaco CMS herunterladen

Jaco CMS ist Freeware: gratis nutzbar, einschliesslich kommerzieller Websites, die Sie damit umsetzen. Die genauen Bedingungen stehen in der LICENSE-Datei im Release-Archiv.

Voraussetzungen

  • PHP 8.2 oder neuer mit den Extensions dom, libxml und openssl
  • Beliebiger Webserver mit PHP – keine Datenbank, keine Build-Tools, kein Composer auf dem Server

Installieren

  1. Aktuelles jaco-dist-*.zip von der Release-Seite laden.
  2. Ins Webverzeichnis entpacken, neben die HTML-Dateien.
  3. INSTALL.md aus dem Archiv folgen: settings.dist.php nach settings.php kopieren, Login setzen, Schreibrechte vergeben.
  4. /jaco/ öffnen und anmelden. Bearbeitbare Bereiche markieren wie in INSTALL.md Schritt 5.

Lokal ausprobieren

Repository klonen, Docker-Image bauen und starten – Login demo / demo. Die drei Befehle stehen im README auf GitHub.
