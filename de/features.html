Jaco CMS Funktionen

Jaco CMS ist für kleine statische Websites gedacht: eine bestehende Website behalten oder eine neue aus einfachem HTML starten. Der Editor kommt nur dorthin, wo Inhalte geändert werden sollen.

Direkt auf der Website bearbeiten

Eine Seite auf der live Website öffnen, einen markierten Bereich anklicken und bearbeiten. Kein separates Inhaltsformular, kein Veröffentlichungsschritt.

  • Inline-Editor: Texte, Überschriften, Links, Bilder und eingebettete Videos direkt auf der Seite.
  • Rich Text: Überschriften, Fett/Kursiv, Listen, Zitate, Code und Links mit einer vertrauten Werkzeugleiste.
  • Inhaltsblöcke: wiederkehrende Bereiche, die Redakteure einfügen, ausfüllen und per Drag and Drop sortieren.
  • Mediathek: bereits hochgeladene Bilder und Dateien wiederverwenden, statt Duplikate anzulegen.

Seiten und Medien verwalten

  • Seitenverwaltung: Seiten aus Vorlagen erstellen, kopieren und löschen; vor Änderungen wird gesichert.
  • Uploads: Bilder und Dokumente mit Endungsprüfung und Grössenlimits; Galerien erzeugen Vollversionen.
  • Stylesheets: das Site-CSS im Admin-Panel bearbeiten, mit demselben Backup-Schutz wie Seiten.
  • Seiteneinstellungen: Seitentitel, Meta-Beschreibung und Robots-Wert bearbeiten, ohne den HTML-Quelltext zu öffnen.
  • Website-Vorlagen: wiederverwendbare HTML-Fragmente unter jaco-data/templates/site/ verwalten und eine Vorlage auf alle markierten Elemente der öffentlichen Seiten anwenden.
  • Rollen: Admin-, Editor- und Viewer-Konten; Viewer können die Website ansehen, ohne sie zu ändern.

Änderungen absichern

  • Backups: jedes Überschreiben oder Löschen behält eine zeitgestempelte Kopie; Wiederherstellen mit einem Klick.
  • Login: tokenbasierte Anmeldung, gedrosselt gegen wiederholte Fehlversuche.
  • Read-only-Übergabe: Viewer-Konten und der Wartungsmodus halten versehentliche Änderungen fern.

Auf dem eigenen Host betreiben

  • Keine Datenbank: Die Seiten sind die Datenbank. Alles liegt in einfachen HTML-Dateien.
  • Kein Build-Schritt: PHP 8.2 oder neuer auf einem typischen Shared Host mit den nötigen Erweiterungen.
  • Kein Lock-in: Marker und Jaco CMS entfernen – das HTML funktioniert weiter.
  • Vier Admin-Sprachen: Deutsch, Englisch, Französisch und Italienisch.

Was Jaco CMS nicht ist

Jaco CMS ist kein visueller Page-Builder, kein Datenbank-CMS und keine Multi-Tenant-Plattform. Es ist ein fokussierter Editor für kleine statische Websites. HTML und Design gehören Ihnen – ob bestehend oder neu. Genau diese Einschränkung hält die Dateien portabel und die Installation klein.
