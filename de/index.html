Jaco CMS

Das Flat-file-CMS, das statische HTML-Dateien direkt im Webverzeichnis verwaltet. Die Seiten sind die Datenbank: kein Datenbankserver, kein Build-Schritt, kein Composer auf dem Server – PHP 8.2 oder neuer auf jedem Shared Host genügt.

Seiten direkt auf der live Website bearbeiten, wiederkehrende Inhaltsblöcke per Drag and Drop verwalten, vor jeder Änderung automatisch sichern. Genau diese Website läuft auf Jaco CMS – die Anleitung unten beschreibt, was Sie hier sehen.
