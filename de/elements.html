Editierbare Inhaltselemente

Jeder Marker, der eine Seite editierbar macht, ist hier an einem live bearbeitbaren Beispiel zu sehen – samt HTML, das ihn erzeugt. Die Navigation bleibt bewusst kurz; die Dokumentation verlinkt hierher.

Einzeiliger Text

<h1 data-jaco-line>A single line</h1>

Ein Einzeiler-Marker ist für Überschriften und kurze Bezeichnungen gedacht.

Rich-Text

<div data-jaco-block><p>Text with <strong>formatting</strong>.</p></div>

Ein Rich-Text-Block unterstützt fett, kursiv, Links, Listen und eingebettete Videos. Der ganze Block wird an einer Stelle bearbeitet.

Videos

<!-- in a text block, added through the video dialog -->
<iframe src="https://www.youtube-nocookie.com/embed/VIDEO_ID"></iframe>

Ein Video kommt über einen Textblock und den Video-Knopf in die Werkzeugleiste.

Bilder

Feste Grösse

Die Datei wird ersetzt; Breite und Höhe bleiben, wie sie im HTML stehen.

Grösse bearbeitbar

<img data-jaco-image data-jaco-image--resizable src="media/team.jpg" width="400" height="225">

Die Datei wird ersetzt, und Breite und Höhe lassen sich im Editor ändern – dafür stehen die Griffe.

In einem Link

<a href="shop.html" data-jaco-link>
  <img data-jaco-image src="media/team.jpg" width="320" height="180">
</a>

Bild und Link werden getrennt bearbeitet: Klick auf das Bild für die Datei, Klick auf den umgebenden Link für sein Ziel. Dieser Link öffnet ein neues Tab – das stellt der Link-Dialog ein.

Galerie

<img data-jaco-image data-jaco-image data-jaco-image--lightbox
     src="media/team.jpg" width="320" height="180">

<!-- nach dem Speichern: der Server legt media/team-full.jpg an und verlinkt sie -->
<a href="media/team-full.jpg">
  <img data-jaco-image data-jaco-image data-jaco-image--lightbox
       src="media/team.jpg" width="320" height="180">
</a>

Das Vorschaubild ist eine kleine Datei; der Galerie-Marker legt eine zweite in Vollgrösse an und verlinkt das Vorschaubild darauf. Wird das Bild ersetzt, entsteht auch ein neues Vollbild. Ein Galerie-Bild, das in einem eigenen Link auf eine Seite zeigt, behält diesen Link – und bekommt kein neues Vollbild.

Wiederholbarer Inhalt: Positionen

Die vier Listen nutzen dasselbe Block-Fragment, aber unterschiedliche Einfügepositionen.

Oben

<div data-jaco-repeater
     data-jaco-repeater--fragment="element-block-de.html"
     data-jaco-repeater--label="Block oben hinzufügen"
     data-jaco-repeater--add="top">
  <div data-jaco-repeater-item>…</div>
</div>

Oberer Block

Neue Blöcke werden oben eingefügt.

Unten

<div data-jaco-repeater
     data-jaco-repeater--fragment="element-block-de.html"
     data-jaco-repeater--label="Block unten hinzufügen"
     data-jaco-repeater--add="bottom">
  <div data-jaco-repeater-item>…</div>
</div>

Unterer Block

Neue Blöcke werden unten eingefügt.

Überall

<div data-jaco-repeater
     data-jaco-repeater--fragment="element-block-de.html"
     data-jaco-repeater--label="Block hier hinzufügen"
     data-jaco-repeater--add="any">
  <div data-jaco-repeater-item>…</div>
</div>

Erster freier Block

Ein Hinzufügen-Knopf erscheint vor jedem Block und nach dem letzten.

Zweiter freier Block

Diese Position passt, wenn die Reihenfolge weniger zählt als das Platzieren neben einem bestimmten Block.

Verschiebbar

<div data-jaco-repeater
     data-jaco-repeater--fragment="element-block-de.html"
     data-jaco-repeater--label="Verschiebbaren Block hinzufügen"
     data-jaco-repeater--add="top" data-jaco-repeater--sortable>
  <div data-jaco-repeater-item>…</div>
</div>

Erster verschiebbarer Block

Dieser Block lässt sich am Griff umsortieren.

Zweiter verschiebbarer Block

Ziehen Sie einen Block, um seine Reihenfolge zu ändern.

Website-Vorlagen

Eine Website-Vorlage ist genau ein markiertes Wurzelelement, gepflegt unter Inhalt → Vorlagen. «Auf alle anwenden» ersetzt jedes Element mit demselben Namen im ganzen Projekt – die Navigation und die Fusszeile dieser Seite sind Beispiele dafür.

<footer data-jaco-template="footer-de.html">…</footer>

Der Wert ist der Dateiname in jaco-data/templates/site/, mit Endung.
