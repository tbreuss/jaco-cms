Jaco CMS

The flat-file CMS that manages static HTML files directly in the web directory. The pages are the database: no database server, no build step, no composer on the server – PHP 8.2 or newer on any shared hoster is all it takes.

Edit pages inline on the live site, manage recurring content blocks by drag and drop, keep automatic backups of every change. This very site runs on Jaco CMS – the manual below describes what you are looking at.
