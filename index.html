You do not need a new CMS project. Jaco CMS adds an editor to the static HTML you already have – or to a new site you build from plain HTML.

Keep your HTML

Design, URLs and markup stay where they are. Existing pages remain plain HTML files under your control.

Mark what editors change

Add the editable markers once. Editors only see the areas they are meant to update – the rest of the page stays fixed.

Edit in place

Log in, click the text or image on the live page and save. Every write keeps a timestamped backup.

No migration. No database. No lock-in. Remove Jaco CMS and the HTML still works. Starting fresh? Use any static HTML template and mark the editable regions once.

Why Jaco CMS?

Edit in place, without HTML

Change text, images, links and videos directly on the live page. Recurring sections can be added and reordered as content blocks – no separate backend screen.

Your HTML stays yours

No database and no export. Every page remains a plain HTML file you can inspect, version and move to another host.

Safe to change

Every overwrite or delete keeps a timestamped backup. Restoring is one click, so a mistake never has to be final.

Four admin languages, source-available freeware, no telemetry and no licence validation.

Who is it for?

Jaco CMS is for small static websites – existing sites that need editing, or new sites built from plain HTML.

Freelancers and agencies

Keep an existing client site, add editing where the client needs it, and hand over content updates without a new CMS project.

Restaurants and cafés

Update the menu, opening hours and seasonal offers yourself – without waiting for a developer or touching the layout.

Studios and practices

Keep services, prices, team details and opening hours current while the design and page structure stay fixed.

Clubs and associations

Add news, events and photos as repeatable content blocks – no HTML knowledge and no separate publishing system.

Small companies

Keep services, locations, team details and opening hours current without turning a simple company site into a CMS project.

Private portfolio sites

Run a small personal or portfolio site and update projects, text and links yourself – without rebuilding the website.

Not a fit for large editorial teams, complex approval workflows or applications that need real-time collaboration. Jaco CMS stays deliberately small.

This site is the demo

Every page you are reading right now is a plain HTML file in this repository, edited through the Jaco CMS admin panel. The headings and paragraphs carry data-jaco-editable-line and data-jaco-editable markers – the same mechanism your own site will use.

Open /jaco/ and log in with demo / demo1234 to try the interface. The public viewer can open the editor, but saving is intentionally disabled. Install Jaco CMS locally or on your own host to edit and save.
