Jaco CMS docs

This page is itself edited with Jaco CMS. The short version: log in, click a marked region, change it and save. The file is written directly.

Installing for the first time? Download the release, open /jaco/install.php and create the first login there. The installer is the preferred path; copying settings.dist.php manually is the fallback for git checkouts.

First 10 minutes

  1. Open the admin: go to /jaco/ below the website address and log in. The public demo uses a read-only viewer account; for editing and saving, install Jaco CMS locally or on your own host.
  2. Edit a page: open the page on the live site, click marked text and change it. Use Save when you are done.
  3. Add content: use the add buttons offered by a content list, fill in the new block, then drag it by the grip to reorder.
  4. Replace an image: click an editable image, then upload a new file or choose an existing one from the media library. Extended image markers also ask for alt text and scaling.
  5. Create a page: use the page manager to create a page from a template, or copy and delete existing pages.
  6. Undo a mistake: open the backup list; every overwrite and delete keeps a timestamped copy. Restore with one click.

Page settings

Use Page settings in the inline editor to change the page title, meta description and robots value. The body is not rewritten. The same fields are available in the raw page editor.

Site templates

Site templates are reusable HTML fragments under jaco-data/templates/site/. Mark an element with data-jaco-template="footer.html" to make it replaceable. Admins edit the template under Content → Templates and can preview the affected pages before applying it to all marked elements. Applying creates a backup of every page it rewrites.

For a bilingual site use separate names, for example footer-en.html with data-jaco-template="footer-en.html" and footer-de.html with data-jaco-template="footer-de.html". Apply to all only touches elements with the same marker; there is no automatic language detection.

How saving works

Saving writes the HTML file directly. A backup is taken first. There is no build step, no database and no separate publish action – the change is live as soon as the file is written.

If something does not work

  • Save is disabled: the account is a viewer. Log in with an editor or admin account.
  • A region cannot be edited: the page does not carry a data-jaco-block data-jaco-block--tools="full" marker there.
  • Nothing can be written: the web server needs write permission for the page and media/ directories.
  • The media picker is empty: upload an image first, or check the configured upload directory.

Going further

Every editable marker is shown on a live example in Editable content elements. Installation details, permissions and the markers in text form are described in INSTALL.md inside the release archive. The CSS editor and the backup list are available from the admin panel. Use the usual platform shortcut to save while an editor has focus.
