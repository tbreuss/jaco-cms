Jaco CMS docs

This page is itself edited with Jaco CMS – everything described below runs on this very site.

Log in

Open /jaco/ below the website address and log in. For a local trial, the login is demo / demo.

Pages

Create pages from a template in the page manager, or edit them inline: open the page on the live site, click into a marked region and type. Saving writes the HTML file directly – with a backup taken first.

Content blocks

Where the template offers an add button, editors insert prebuilt blocks (news items, teasers), fill them in and reorder them with the grip handle. No HTML knowledge required.

Images and files

Upload images and documents in the upload manager, then swap them into image regions or link them from text. Galleries pair thumbnails with full versions automatically.

Backups

Every change keeps a timestamped copy in the backup list. Restoring is one click; deleting a backup is the only irreversible action in the panel.

Keyboard shortcuts

Save with the usual shortcut of your platform wherever an editor has focus.
