Download Jaco CMS

Jaco CMS is freeware: free to use, including commercial websites you build with it. See the LICENSE file in the release archive for the exact terms.

Requirements

  • PHP 8.2 or newer with the dom, libxml and openssl extensions
  • Any web server with PHP – no database, no build tools, no composer on the server

Install

  1. Download the latest jaco-dist-*.zip from the releases page.
  2. Unpack it into your web directory, next to your HTML files.
  3. Follow INSTALL.md from the archive: copy settings.dist.php to settings.php, set a login, grant write permissions.
  4. Open /jaco/ and log in. Mark editable regions as described in INSTALL.md step 5.

Try locally

Clone the repository, build the Docker image and run it – login demo / demo. The README on GitHub has the three commands.
