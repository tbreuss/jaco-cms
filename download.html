Download Jaco CMS

Jaco CMS is freeware, including commercial websites you build with it. The exact terms are in the LICENSE file in the release archive.

Requirements

  • PHP 8.2 or newer with the dom, libxml and openssl extensions
  • A web server with PHP and write access to the website files
  • No database, no build tools and no Composer on the server

Install in three steps

  1. Download the latest jaco-dist-*.zip from the releases page and unpack it into your web directory, next to the HTML files you want to edit.
  2. Open /jaco/install.php in the browser and create your login, language and upload directory. The installer writes settings.php and removes itself afterwards.
  3. Grant write permissions for the editable HTML files, jaco/_backup/, upload/ and jaco/runtime/log/ as described in INSTALL.md. Then open /jaco/ and log in.

The installer is the preferred installation path. Copy settings.dist.php to settings.php manually only when working from git or when the installer cannot write the settings file.

Before you install

  • Make a backup of the existing website first.
  • Jaco CMS works with static HTML files; it is not a fit for dynamic applications.
  • Editable regions must be marked once as described in INSTALL.md.
  • The public demo is read-only; use a local or separate installation to edit and save.
