Editable content elements

Every marker that makes a page editable is shown here on a live example, with the HTML that produces it. The navigation stays short on purpose; the documentation links here.

Contents

  • Single-line text – plain, basic
  • Rich text – plain, basic, full
  • Videos – a tool of the full block
  • Links – same tab, new tab, around an image
  • Images – replaced as it is, fill, fit, choice
  • Repeatable content – top, bottom, any, sortable, no label
  • Site templates – top level and in a folder

Single-line text

A single-line marker is intended for headings and short labels.

Plain

<h1 data-jaco-line>A single line</h1>

A single line without tools: the text is edited, nothing is formatted.

Without --tools the editor offers no formatting at all.

Basic

<h1 data-jaco-line data-jaco-line--tools="basic">A single line</h1>

A single line with bold, italic, underline, strike and a link.

A line offers basic or nothing; headings and lists belong to a block.

Rich text

Plain

<div data-jaco-block><p>A paragraph.</p></div>

A block without tools: paragraphs and line breaks, nothing else.

Without --tools the editor offers no formatting, and a <strong> written by hand is removed when the page is saved.

Basic

<div data-jaco-block data-jaco-block--tools="basic"><p>Text with <strong>formatting</strong>.</p></div>

A block with bold, italic, underline, strike and a link, but no structure.

A heading or a list inside a basic block loses its markup when the page is saved.

Full

<div data-jaco-block data-jaco-block--tools="full"><p>Text with <strong>formatting</strong>.</p></div>

A rich-text block supports bold, italic, links, lists and embedded videos. The whole block is edited in one place.

Videos

<!-- in a text block, added through the video dialog -->
<iframe src="https://www.youtube-nocookie.com/embed/VIDEO_ID"></iframe>

A video is added from a text block with the video button in the toolbar.

Links

<a href="download.html" data-jaco-link>Same tab</a>

<a href="download.html" target="_blank" data-jaco-link>New tab</a>

Same tab New tab

Both the URL and target are changed through the link dialog.

Images

Replaced as it is

<img data-jaco-image src="media/team.jpg" width="320" height="180">

Without --mode the file is stored as the redactor uploaded it; width and height only shape the layout.

Fixed size

<img data-jaco-image data-jaco-image--mode="fill" src="media/team.jpg" width="320" height="180">

The file is replaced; width and height stay as they are in the HTML.

Fit

<img data-jaco-image data-jaco-image--mode="fit" src="media/logo.jpg" width="320" height="180">

The file is scaled so the whole image fits into width × height; the rest of the box stays empty. Use it for a logo or a diagram that must not lose anything.

Size editable

<img data-jaco-image data-jaco-image--mode="choice" src="media/team.jpg" width="400" height="225">

The file is replaced and the width and height can be changed in the editor – the handles stand for that.

Inside a link

<a href="shop.html" data-jaco-link>
  <img data-jaco-image src="media/team.jpg" width="320" height="180">
</a>

The image and the link are edited separately: click the image for the file, the surrounding link for its target. This link opens in a new tab, which the link dialog sets.

Repeatable content

The four lists use the same block template but different insertion positions.

Top

<div data-jaco-repeater="element-block-en.html"
     data-jaco-repeater--label="Add top block"
     data-jaco-repeater--position="top">
  <div>…</div>
</div>

Top block

New blocks are inserted at the top.

Bottom

<div data-jaco-repeater="element-block-en.html"
     data-jaco-repeater--label="Add bottom block"
     data-jaco-repeater--position="bottom">
  <div>…</div>
</div>

Bottom block

New blocks are inserted at the bottom.

Any

<div data-jaco-repeater="element-block-en.html"
     data-jaco-repeater--label="Add block here"
     data-jaco-repeater--position="any">
  <div>…</div>
</div>

First any block

An add button appears before every block and after the last one.

Second any block

Use this position when order matters less than placing a block next to another one.

Draggable

<div data-jaco-repeater="element-block-en.html"
     data-jaco-repeater--label="Add draggable block"
     data-jaco-repeater--position="top" data-jaco-repeater--sortable>
  <div>…</div>
</div>

First draggable block

This block can be reordered with the grip handle.

Second draggable block

Drag a block to change its order.

Without label

<div data-jaco-repeater="element-block-en.html" data-jaco-repeater--position="top">
  <div>…</div>
</div>

So far without buttons

The add button says "Add block" in the editor's language.

Without --label the button is translated by the editor, so the page does not decide the language.

Site templates

A site template is one marked root element, maintained under Content → Templates. "Apply to all" replaces every element that carries the same name across the project — the navigation and the footer on this page are examples of it.

Top level

<footer data-jaco-template="footer-en.html">…</footer>

The value is the file name in jaco-data/templates/site/, extension included. The footer at the bottom of this page is this template.

In a folder

<footer data-jaco-template="footers/footer-en.html">…</footer>

The value is the path relative to jaco-data/templates/site/: segments separated by /, each of them letters, digits, - and _. No page in this project uses a folder yet; the rule is the same one fragments follow.
